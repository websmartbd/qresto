# DineQR 🍽️
> Modern, bilingual (Bengali & English) QR Code Restaurant Menu, Table-side Ordering & Real-time Kitchen Management System.

Built with lightweight vanilla JS, Tailwind CSS, and Supabase (with built-in offline/demo data mode).

---

## ✨ Features

- **📱 Customer Experience:**
  - Fast, responsive digital showcase on desktop & app-like experience on mobile.
  - Interactive table ordering via QR code (`menu.html?table=1`).
  - Item customisation (variants, addons, spice level, kitchen notes).
  - Live cooking progress & order status tracking.
  - Table waiter call notification.

- **🧑‍🍳 Kitchen & Admin Management:**
  - Live order docket with sound alerts & KOT print view.
  - Multi-status workflow (`Received` → `Cooking` → `Served` → `Paid`).
  - Table management & QR code generator.
  - Comprehensive sales reports, daily trends & category analytics.
  - Visual theme engine with custom brand colors.
